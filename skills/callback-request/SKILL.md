# Callback request

The person can't talk now. Respect that.

## What to do

1. Say yes and keep it short.
2. Ask when is better: a day and a rough time.
3. Repeat the day and time back to them.
4. Thank them and end the call.

## What not to do

- Don't try to squeeze in "just one quick thing".
- Don't ask why now is a bad time.
- Don't argue if they won't name a time. Just thank them and end the call.
- Don't promise an exact time. The system decides when calls are allowed.

## Example lines

- "Of course. When would be a better time?"
- "So Tuesday afternoon. Thanks, talk to you then."
- "No problem. Have a good day."
